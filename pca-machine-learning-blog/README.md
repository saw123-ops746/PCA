# Principal Component Analysis (PCA) Explained: Breast Cancer Wisconsin Case Study

A static educational website (HTML, CSS, vanilla JavaScript, MathJax) that teaches PCA with one real dataset, worked maths and eight graphs generated by Python. Educational only: nothing here is a diagnostic tool or medical advice.

## Learning objectives
Understand dimensionality reduction, variance, covariance, eigenvalues/eigenvectors, standardisation, explained variance, scores vs loadings, reconstruction error, leakage-safe workflows, and PCA's limitations.

## Website features
Responsive layout, table of contents with scroll-spy, graph gallery, collapsible advanced maths and interview answers, MathJax formulas, dataset download links.

## Technologies
HTML5, CSS3, vanilla JavaScript, MathJax; Python (pandas, NumPy, Matplotlib, Seaborn, scikit-learn); Git/GitHub; Netlify.

## Project structure

## Dataset, attribution and provenance
Breast Cancer Wisconsin (Diagnostic), UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic (W. N. Street, W. H. Wolberg, O. L. Mangasarian, 1993; UCI lists it under CC BY 4.0, please confirm on the dataset page).
569 samples (357 benign, 212 malignant), 30 numeric features, no missing values.

**Conversion note.** The UCI site was not reachable when this project was built, so `data/breast_cancer_wisconsin.csv` was written from the copy of the same Diagnostic dataset bundled with scikit-learn (`sklearn.datasets.load_breast_cancer`). Differences from the UCI file: there is no `id` column (the code drops `id` automatically if your file has one); `diagnosis` is derived from the target (0 = M, 1 = B); feature names use scikit-learn's wording ("mean radius", "radius error", "worst radius"). Values are unchanged. To use the UCI original, convert `wdbc.data` to CSV with a `diagnosis` column and numeric features and replace the file.

## The eight visualisations
1 raw 2-feature scatter, 2 correlation heatmap, 3 before/after rotation on two features, 4 scree plot, 5 cumulative variance, 6 PC1 vs PC2 (diagnosis only colours points), 7 loadings heatmap (first 5 PCs), 8 reconstruction error.

## Setup and graph generation
```
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python generate_graphs.py
```
The script writes the PNGs and `results.json`. Numbers in the article text came from that file (tested with scikit-learn 1.8); if you change versions or settings, recheck the text against it.

## Run locally
`python -m http.server 8000`, then open http://localhost:8000 (Python is needed only to regenerate graphs or serve locally, not to host the finished static site).

## Deploy on Netlify
